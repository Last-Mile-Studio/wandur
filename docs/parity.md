# Feature parity

Status of every feature of the C# client (main at 27f66d2, plus the `feature/mudlet-import`
branch) in the Rust client, after parity tasks t01 to t16 (2026-10-09).

Status values, in the Status column:

- **Done**: works in the Rust app and is tested. Deliberate differences from C# are named in
  brackets and explained under Details.
- **Partial**: works, but a named part of the C# feature is missing or untested. The Status cell
  says what.
- **Deferred**: not built, with the reason.
- Out of scope: not part of this client.

Final audit, 2026-10-09 at 9e55a7c: 38 Done, 16 Partial, 3 Deferred (one is the update check, whose install id
half is done), 1 out of scope. The summary and open findings are in `docs/parity-report.md`.
Since then (2026-10-09): the import of C# client data is Done (`docs/csharp-import.md`), so 39
Done, 16 Partial, 2 Deferred, 1 out of scope.
